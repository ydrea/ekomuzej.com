Here you can download for free the educational game Zagreb Monuments, which illustrates one of the possible scenarios of using a mobile application in the design of an ecomuseum.

The demo application is available for the Android platform.

Installation instructions

To install the application on your Android device, you need to enable installation from unknown sources in the device's security settings.

After downloading the APK file, open it via a file manager or directly from the browser to start the installation process.

Please note that your device may display a security warning when installing an application outside of the Google Play Store. This is a standard security measure and you can safely proceed with the installation if you have downloaded the application from a trusted source.

After installation, find the application icon on your home screen or your application list and launch it to start exploring Zagreb Monuments through our educational game.

Enjoy discovering the rich history of Zagreb through an interactive and fun game!
